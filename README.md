# digital-twin

- [Partner playbook](docs/playbook/README.md): how we run an engagement (phases, discovery, stakeholders, stories).
- [Compendium](docs/compendium/README.md): what is true about Claude, and our default technical stance.
- [Starter kit](starter-kit/README.md): the marketplace, plugins, templates and settings we build with, and how to use them on an engagement.
