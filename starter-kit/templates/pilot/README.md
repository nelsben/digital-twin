# Pilot templates

Three fill-in files for the pilot of one role twin. Each backlog for a pilot has a task for each of them, so this folder gives that task something to copy.

## What is here

| File | What it is for |
|---|---|
| [scorecard.md](scorecard.md) | The monthly scorecard for one twin: a table per layer, a row per task, and the decision to stay, move up one level or move down. |
| [memory-policy.md](memory-policy.md) | What the twin may remember and what it must not, for one role, with the sign-off. |
| [pilot-training.md](pilot-training.md) | The 45-minute session for pilot users, and the form for reporting a failure or a wrong draft. |

These files state no fact about Claude. Where one is needed, they link the [compendium](../../../docs/compendium/README.md).

## Fill them in

1. Copy the folder into [the customer's delivery repo](../../README.md#start-a-new-customer) or into the customer's engagement folder.
2. Fill in each `FILL IN` cell. Each one says where in the engagement's design the answer comes from. Write "not available" instead of leaving a cell empty when a source does not exist.
3. Delete the comment at the top of each file and every `FILL IN` marker.
4. Copy `scorecard.md` again each month. Keep the old copies: the "Last month" column reads from them.

## When to use them

These files belong to the Pilot phase of the [engagement model](../../../docs/playbook/01-engagement-model.md). Settle the memory policy and the training before the first pilot user starts, and the first scorecard at the end of the first month. They stay in use in the Scale phase, when a promotion needs scorecard evidence.
