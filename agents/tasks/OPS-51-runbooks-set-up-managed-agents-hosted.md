## Why

The generated backlog's set-up tasks for hosted runtimes link to compendium page 05, which helps choose a runtime but does not say how to set one up, and nothing says what turns an event into a session. The consultant-walk review (OPS-44) judged that an engineer could not build from the backlog alone. These runbooks are the missing how-to; another card points the backlog at them.
