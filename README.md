# digital-twin

Partner playbook and knowledge base for delivering Claude "digital twins": role-based companion agents with bespoke skills, deployed into customers' Claude orgs.

- [Partner playbook](docs/playbook/README.md): how we run an engagement (phases, discovery, stakeholders, stories).
- [Compendium](docs/compendium/README.md): what is true about Claude, and our default technical stance.
- [Starter kit](starter-kit/README.md): the marketplace, plugins, templates and settings we build with, and how to use them on an engagement.
- [Partner kit](partner-kit/README.md): the persona-card workflow, from interview notes to a levelled plan, a backlog and a dashboard that also shows each artifact's build and deployment status. Partner-only; never installed in a customer org.
- [Engagements](engagements/README.md): one folder per customer, and the two fictional worked examples.
