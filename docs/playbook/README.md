# Digital twin partner playbook

We are Anthropic partners. We deliver digital twins **into our customers' Claude orgs**: we run discovery, write the stories, define the stakeholders and do the implementation.

- **This playbook** covers *how we run an engagement.*

## Defaults are not decisions

Anything the compendium marks **"Decided"** is our **default stance**. Confirm it with each customer in discovery. For example:

- 30-day retention for private-equity chat
- soft walls, enforced through role-based access in Salesforce, HubSpot and SharePoint
- the Director of IT as technical owner and the RevOps manager as business owner.

Record the customer's answer in their engagement folder, not in the compendium.
